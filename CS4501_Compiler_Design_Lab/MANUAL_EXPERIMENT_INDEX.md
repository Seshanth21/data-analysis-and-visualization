# CS4501 manual experiment index

The repository follows the ten experiments listed in the CS4501 Compiler Design laboratory manual:

1. Lexical analyzer for C patterns and a symbol table for identifiers.
2. Lexical analyzer using LEX.
3. Recognizer for arithmetic expressions using `+`, `-`, `*`, and `/`.
4. Recognizer for variables beginning with a letter and followed by letters or digits.
5. Recognizer for C control-structure syntax.
6. Calculator using LEX and YACC.
7. Three-address-code generation using LEX and YACC.
8. Type checking using LEX and YACC.
9. Constant folding, strength reduction, and algebraic transformation.
10. Compiler back end translating three-address code into 8086-style assembly.

The original institutional manual is not redistributed in this repository. `SOURCE_ALIGNMENT.md` identifies the small changes needed to make the supplied examples reproducible with current GNU Flex, GNU Bison, and GCC.
